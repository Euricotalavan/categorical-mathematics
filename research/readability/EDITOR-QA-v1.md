> **未採納為正式規範。** 只可在本卷已授權 A/v3 第08–09步，或明確選用 B 後的 B-06 內作為方法參考。正式 Study、正文、章號和終審權限不因此變更。

## 1. 接收（不可省略）

- [ ] 記錄本卷 **A/B** 選擇、授權、階段和凍結範圍；未選 B 則用 A/v3。
- [ ] 實際讀入唯一正式正文、覆蓋表、缺陷表、重要 OPEN/UNKNOWN、符號與先備慣例；列出版本／hash，不只信上游自稱 `reviewed`。
- [ ] 固定 Study 模板版本、字型／套件、編譯入口、有效 Git commit 與已發布前卷末章；檢查章節、定理、例題、引用和書籤連續。
- [ ] A 接精修完成的整卷內容；B 只接 B-05 已完成章級與整卷整合的正文。缺檔只阻受影響部分，不要求全卷重做。

## 2. 沿正文讀一遍，標出「第一個卡住的地方」

每項記原文和頁／節／標籤，而非寫「這頁不夠順」。依問題歸屬：

| 類別 | 可直接處理 | 必須轉交 |
|---|---|---|
| `L` 版面 | 字體、行距、公式換行、圖文貼近、分頁、對比 | 若要改變數學表示，交精修確認 |
| `E` 非語義行文 | 刪無用重述、拆長句、把 Why 靠近關鍵句 | 影響條件／量詞／符號語意就退精修 |
| `N` 敘事及先備 | 標示例子過晚、前引不明與缺少操作進展 | 擴充調敘事；精修查依賴／數學 |
| `M` 數學 | 只能定位問題、說明何處不清楚 | 精修核真偽；大幅展開不足交打厚，不能自己腦補後放行 |

## 3. 按內容類型安排視覺，不追求每頁塞滿

- [ ] 短定義與必要前提同頁或明確相連；長定義**可分頁**並帶續接標識。
- [ ] 短 Remark 的醒目句與短 Why **就地、同框、同頁**；必要數學不要降成選讀小字。
- [ ] 長證明按推理步驟合理分頁，不套不可跨頁巨框；續頁能辨認仍在證明何事。
- [ ] 多行公式的環境真的可安全換頁；檢查每個項、每個運算符、每個假設仍在。
- [ ] 大矩陣／交換圖先改布局或明示表示方式，不擅自縮字、換記號或移除內容。
- [ ] 圖與相應計算相近，表格長到跨頁時能辨識表頭與單位；演算法保留停止條件。
- [ ] 定義、例題、命題、證明、Remark 的顏色與標題層次一致；同一頁不要處處搶眼。
- [ ] 保留寬鬆行距、醒目但有節制的色彩；長頁寧願自然多頁，不靠無意義的 `\newpage`。

## 4. 技術驗證：三種證據分開出具

### A. 內容保留

- [ ] 鎖定來源／manifest；修改前後 diff；核標籤、數學文字、公式及必要例題。
- [ ] 修改條件、定義、符號或依賴時，標出所有可能失效的後文審核，交內容官重核。
- [ ] 同一內容可以有多種 profile，但不可多份互相競爭的正式正文。

### B. PDF 工程

- [ ] 以固定 XeLaTeX/latexmk 乾淨編譯，記環境及字型實際解析結果；不把成功退出視為通過。
- [ ] 查缺字、意外白字／低對比、超界、壞引用、圖像／字型、書籤、PDF 頁標籤與交叉連結。
- [ ] 查**預期內容是否真的全部出現在 PDF**：文字可抽取仍可能在可見頁界之外。
- [ ] 用故意壞掉的負向測試確認檢查工具會抓到長式溢出、壞引用、分離 Why、意外文字顏色。
- [ ] 記來源、PDF bytes、SHA256及重編／渲染比對範圍；不同 PDF 二進位不能靠猜測簽章原因當作同一檔。

### C. 閱讀檢查

- [ ] **實際渲染每一頁、依順序檢視**，不只看擷取文字或抽樣縮圖；疑難公式和異常頁放大。
- [ ] 記錄是否出現「一大坨字」、重複強調同一句、脫離主線的補充、孤立標題、極短末頁、視線被迫跳轉。
- [ ] 檢查跨頁後仍清楚哪個命題在證、哪個公式在推，圖與相關解釋沒有被拆散。
- [ ] 全章連續順讀；頁面密度數字只能用來找異常，不能用來自動刪文或宣稱可讀。

## 5. 修改的回歸範圍

| 修改 | 至少重核 |
|---|---|
| 非語義詞句調整 | 本段及相鄰段落、引用、實際頁面與分頁傳播 |
| 框線、留白、圖文位置 | 改動頁與相鄰頁、跨頁關係、相關多輸出設定 |
| 全域字型、字級、行寬、色彩或模板 macro | 所有受影響章節／profile 全頁重編、差異定位與視檢 |
| 數學條件、記號、定義、先備 | 負責內容角色重核直接及傳遞依賴；影響不明就擴大 |

**已經修好的項目保留證據，不因換對話重新審成未完成。** 修補不能只看 Git diff；小改動可能改變所有後續分頁。

## 6. 階段完成／正式交接

- [ ] 產出可恢復來源 ZIP + 對應 PDF；核版本、bytes、SHA256、編譯入口與依賴、輸出所對應的唯一正文。
- [ ] 保留同一缺陷表：`ID | 原文/頁段 | 問題與影響 | 修改後文字/布局 | 責任官 | 重核證據 | OPEN/UNKNOWN`。
- [ ] 分列**內容語義狀態**、**工程狀態**、**全頁視檢狀態**、**使用者偏好／理解測試狀態**；無法驗證就寫 UNKNOWN。
- [ ] 完整交接列角色、卷號、A/B採用授權、固定 Git commit／前卷末章、來源/PDF／模板版本、變更影響、未決阻塞、下一唯一階段、禁止重做、送達與讀入證據。
- [ ] 交付候選只交**打厚官最嚴格整卷終審**；任何修正再回打厚複核。沒有「兩份 NO OBJECTIONS 就結案」。
- [ ] **研究模板不自動採納**；只有另經使用者明確授權，才修改正式模板或發布內容。對公開 Git 上傳另核庫可見性、版權、來源及權限。
