# 數學語言與自然語言：證據、判準與原型例子

研究日期：2026-11-18。研究子任務：英文與數學符號取捨、AI 無功能重述。狀態：研究草案，非正式製作規範；原研究子任務執行時沒有改動正式教材、模板、工作流或 GitHub；研究完成後另獲授權公開提交本文，正式資料仍不變。

## 1. 本輪可支持的結論

**安全符號化必須同時通過「數學等價」與「讀者能解碼」兩道檢查。** 一個改寫可以數學上完全等價，卻對尚未掌握記號的讀者更難讀；一個更短、更順的式子也可能偷偷增加了型別、唯一性或一致性的假設。

符號最適合承載已界定物件之間的精確關係、可比較的量詞順序、重複運算與結構。文字最需要保留在：指出當前目的、解釋方法選擇、標出條件依賴、建立新記號的解碼方法、澄清容易混淆的物件，以及讓長論證在轉折與翻頁後繼續。這是一項可檢驗的設計提案，不是已證明讓本套書達到 90 分的處方。

**冗餘不能只按命題資訊量判定。** 「N 不依賴 x」可能已由量詞順序邏輯蘊含，但在首次教一致收斂時有明確的辨識功能；逐字翻譯同一串量詞三次則未必有功能。要問的是這句話讓指定讀者完成哪一項辨識、推理或使用任務，而不是它是否提出另一個定理。

## 3. 三類處理判準

### A. 可進入「安全符號化」候選

須同時具備以下證據：

1. 原文物件、定義域、陪域、型別、所有自由變項已在有效上下文中確定。
2. 記號已教過，或本段正明確建立記號；不能只因模型熟悉而視為讀者已知。
3. 改寫前後條件、量詞順序、作用域、依賴、關係種類和一般性一致。
4. 原段是在陳述同一性質或運算，不是正在證明其存在、唯一、良定或適用。
5. 改寫沒有移走本次推理所需的理由、方法選擇或辨識例子。
6. 讀者可以從已讀正文展開新式子，不需借用未引入定理或新慣例。
7. PDF 中新式子不靠縮字、擠壓間距或含混斷行換取短度；跨行作用域仍清楚。

「可進候選」不代表自動採用。精修內容角色核等價後，行文排版角色才處理其呈現；排版角色不能自行改量詞或型別。

### B. 必須保留必要文字，允許精確縮寫

下列文字可能不增加新命題，卻有獨立教學功能：

- **目標**：這一步要證哪個子結論，為何它足以完成全證明。
- **選法**：為何固定這個索引、引入此輔助物件或使用此定理。
- **依賴**：常數依賴哪些參數、哪些參數必須保持一致。
- **解碼**：新記號指的是哪類物件，如何讀其作用域與組成。
- **辨識**：例子如何滿足定義；反例究竟違反哪個條件。
- **銜接**：上一步所得結果如何供下一步使用，尤其是長證明與跨頁處。
- **防誤解**：等號是否為字面相等、是否僅有同構、運算是否有定義。

這些功能不需要各自一個框或一段。可以用一句有內容的文字、公式旁的理由、帶型別的命名，或在必要位置的一次短提醒完成。

### C. 必須退相應數學內容角色

- 需要新增或推定假設，才能證明改寫等價。
- 型別、定義域、陪域或物件同一性不明；不同來源的慣例衝突。
- 更動量詞順序、常數依賴、嚴格/非嚴格不等號、相等/同構/等價/包含。
- 用一句「良定」或一個箭頭取代尚未完成的存在、唯一、封閉或代表元獨立性證明。
- 將點態改成一致、局部改成全局、固定參數改成任意參數、有限改成無限。
- 以一般符號取代特例計算，卻未證明一般式；省去必要的例題辨識。
- 新表示使讀者必須使用尚未引入的工具，即使對作者而言更短。

缺失資料標 UNKNOWN。無法完成核對時維持原文並提出具體問題，不用模型補出的常識暗填。

## 4. 十四個原創數學對照例

本節例子是**本輪自製的判準示例**，不是從 P2/P3 擷取的失敗原文，也不是新讀者效果測試。英文示例為本輪自寫；數學核對為逐項邏輯核對，不等於獨立真人審核。外部研究支持研究方向，不為這些個別改寫提供效果分數。

### E01. 映射的陪域：不能把像落入 B 改寫成同一映射以 B 為陪域

**有效上下文**：已給定 f:A→C，且 B⊆C。

**原句**：For every x in A, the value f(x) belongs to B.

**可安全緊縮**：f(A)⊆B。

**高風險改句**：f:A→B。

後者把陪域 C 改成 B；在把陪域視為映射資料的慣例中，這是一個 corestriction，不是同一宣告。即使採圖像式集合定義，也必須確認此處既有慣例。若有需要，可明寫「Let f̄:A→B be the corestriction, f̄(x)=f(x).」並交內容角色核查。

**反查**：令 f:ℝ→ℝ 為 f(x)=x²，B=[0,∞)。f(ℝ)⊆B 成立；不宜默默把原物件的陪域改掉。若原文只說 ∀x∈A f(x)∈B，甚至不能由此推出 dom(f)=A；空集 A 時該性質可空真。

### E02. 包含關係：安全縮寫與嚴格包含須分開

**原句**：Every element of A is an element of B.

**改句**：A⊆B。

前提是正文已約定 ⊆ 的含義。不能改成 A⊊B；A=B 是反例。若某領域用 ⊂ 同時表示非嚴格包含，應依現行記號表，不能讓精簡引入歧義。首次介紹包含時，保留元素判準不是廢話，因為它教讀者如何使用記號。

### E03. 一致收斂：公式呈現順序，一句文字指明依賴

**上下文**：f_n,f:X→ℝ，n∈ℕ。

**可用定義**：

    ∀ε>0 ∃N∈ℕ ∀n≥N ∀x∈X : |f_n(x)−f(x)|<ε.

**應保留的短句**：The same N works for every x∈X.

它指出一致性差異，並非把整個式子再譯一遍。不能移成 ∀x∈X ∀ε>0 ∃N∈ℕ ∀n≥N，因為那是點態收斂。

**反查**：在 X=[0,1) 取 f_n(x)=x^n、f=0。每個固定 x 有 x^n→0；但每個 n≥1 都有 sup_{x∈[0,1)}x^n=1，所以不是一致收斂。此處「sup=1」不是「某點取到最大值 1」。

### E04. 存在唯一：短符號不代替兩項證明義務

**上下文**：a,b∈ℝ 且 a≠0。

**原句**：There is exactly one real number x satisfying ax=b.

**可緊縮陳述**：∃!x∈ℝ : ax=b。

若已是證明，仍需兩件事：x=b/a 給出存在；若 ax=ay=b，則 a(x−y)=0 且 a≠0，故 x=y。不得把長段 proof 改成單獨 ∃! 而宣稱嚴謹性未變。首次教 ∃! 時也需讓讀者知道它同時要求存在與至多一個。

### E05. 商物件良定：一個箭頭不能取代代表元檢查

**上下文**：m,k 為正整數。

**候選定義**：φ:ℤ/mℤ→ℤ/kℤ，φ([a]_m)=[a]_k。

**數學義務**：這個規則良定當且僅當 k|m。若 a≡b mod m，則 a−b=tm；當 k|m 時推出 a≡b mod k。反向由 [0]_m=[m]_m 得 k|m。

**必要短句**：The value must be independent of the representative.

它給讀者檢查目標。不能因映射已排成一行，就把上述義務當作解決。反例 m=2、k=3： [0]_2=[2]_2，但 [0]_3≠[2]_3。

### E06. 同構與相等：座標式需要基底

**上下文**：V 是 n 維 F-向量空間，B=(v₁,…,v_n) 是已固定的有序基底。

**可精確表達**：c_B:V→F^n，Σ_i a_i v_i↦(a₁,…,a_n) 是線性同構。

**不能省成**：V=F^n。

唯一座標來自 B 是基底；同構還依賴 B。若移除 B，下標與一句依賴說明，讀者可能誤以為有不需選擇的指定同構。對一般 n 維空間，存在同構並不表示物件字面相等。

### E07. 複合映射：符號比逐箭頭敘述更容易核型別

**上下文**：f:A→B，g:B→C，h:A→D，k:D→C。

**原句**：For every a in A, applying g after f gives the same result as applying k after h.

**可緊縮**：g∘f=k∘h。

所有箭頭都已明列，兩側同為 A→C。若首次介紹交換圖，可保留「Both paths from A to C give the same map.」作解碼，不需把每個函數的作用順序再長譯。若把式子改成 f∘g=h∘k，通常連型別都不成立。

### E08. 長證明的方法選擇：留下原因，縮去逐步播報

**命題**：度量空間 X 上，連續實值函數 f_n 一致收斂到 f，則 f 連續。

**應保留的目的句**：Fix one approximating function first, so that its continuity controls the middle term.

固定 x₀∈X、ε>0。先由一致收斂選 N，使所有 x∈X 都有 |f_N(x)−f(x)|<ε/3；再由 f_N 在 x₀ 連續，取 δ>0，使 d(x,x₀)<δ 時 |f_N(x)−f_N(x₀)|<ε/3。於是

    |f(x)−f(x₀)|
    ≤ |f(x)−f_N(x)| + |f_N(x)−f_N(x₀)| + |f_N(x₀)−f(x₀)|
    < ε.

「先固定 N」有功能：保證選 δ 時使用同一個 f_N。可以刪掉「We now apply the triangle inequality, which is an important inequality that will allow us to estimate the difference」這種長播報，改成等式鏈旁一次標明 triangle inequality。不能只留三項式而隱去 N、δ 的選取。

### E09. 消去條件：表面流暢可能刪掉解

**錯誤緊縮**：x²=x ⇒ x=1。

**完整緊縮**（x∈ℝ）：x²=x ⇔ x(x−1)=0 ⇔ x∈{0,1}。

若原段真的已假設 x≠0，才可消去 x。類似地，在範疇論中從 m∘u=m∘v 推出 u=v，需要 m 為 monomorphism；不能因兩邊看起來有相同前綴就消去。這屬內容審核，非排版或普通英文刪減。

### E10. 關係的方向：反向翻譯比字面替換可靠

**自製原句**：The number of red counters is three times the number of blue counters.

令 r、b 分別是紅、藍籌碼的數量，則 r=3b；不是 3r=b。

可用 b=2、r=6 反查方向。此例本身是自製的；S02 的實驗支持的是翻譯可能有系統性錯誤，不是此自製題的錯誤比例。若縮寫前沒有說清 r、b 是數量而不是物件名稱，應先補型別。

### E11. 定義與證明：把「線性」寫成公式不等於完成核對

**上下文**：T:V→W，V、W 為同一域 F 上的向量空間。

**定義形式**：

    T(αu+βv)=αT(u)+βT(v)  (u,v∈V; α,β∈F).

它可以取代冗長的「addition and scalar multiplication」逐項翻譯。若段落要證明具體映射 T(p)=p+p′ 線性，仍須寫出微分的線性如何給出該等式，或明確引用已證結果；定義式不是對具體 T 的證明。若未固定共同的域 F，還有型別／scalar convention 問題。

### E12. 局部與全局：一個 c 不能抹去參數依賴

**條件甲**：∀x∈X ∃C_x>0 ∀n∈ℕ : |u_n(x)|≤C_x。

**條件乙**：∃C>0 ∀x∈X ∀n∈ℕ : |u_n(x)|≤C。

乙較強。取 X=ℝ、u_n(x)=x，甲成立（例如 C_x=|x|+1），乙不成立。把文字「for each x, the sequence is bounded」改成「|u_n(x)|≤C」而不標作用域，會隱去這個差異。應保留一句 C may depend on x，或直接以清楚量詞呈現。

### E13. 可刪的 AI 轉場，與不可刪的方法目的

**自製原句**：It is important to observe that the following calculation is useful because it will help us understand the inverse more clearly. We now proceed to compute the inverse in a systematic way.

若下一式直接做可逆矩陣計算，這兩句沒有指出特定方法或理由，可刪。較有內容的替代（在 D³=0 已證時）是：

**改句**：Since D³=0, the geometric expansion stops after D².

    (I+D)(I−D+D²)=I+D³=I.
    (I−D+D²)(I+D)=I+D³=I.

這句解釋為何試該多項式。若只證左或右逆，應依空間及環的假設判定是否已足夠，不能一律當作雙側逆。在此兩個乘積皆展開，避免暗用有限維假設。

### E14. 敘事上有用的重述：例後只保留新增辨識

定義 injective 後已寫 f(x)=f(y)⇒x=y，例子 f:ℝ→ℝ、f(x)=x² 顯示 f(1)=f(−1)。

**可刪的重述**：This means that the function is not injective, and therefore it fails to be an injective function.（若前一句已下相同結論。）

**應保留的辨識**：The two inputs must be distinct; finding two equal outputs at the same input proves nothing.

後一句指明反例義務。若本書已反覆使用且讀者熟練，可不必每次重複；首次學會找反例時不能只按資訊重複率刪去。敘事是否需要這句仍須代表樣本讀者驗證。

## 5. AI 廢話診斷：把「像廢話」改成可追查判定

### 5.1 句子功能標註

對每句／每段標一個或多個主要功能：

| 代碼 | 功能 | 刪除前必問 |
|---|---|---|
| M | 定義、假設、量詞、結論、推導 | 數學義務是否原封保留？ |
| G | 推理目標、證明結構、方法選擇 | 讀者還知道下一步為何如此嗎？ |
| D | 記號、型別、作用域解碼 | 僅靠已讀正文能正確解碼嗎？ |
| E | 例子辨識、反例、有效直觀 | 能辨識符合與不符合的對象嗎？ |
| W | 防誤解、依賴限制、邊界提醒 | 哪個具體錯誤會因此不再被防止？ |
| C | 必要銜接、重啟上下文 | 跨段／跨頁後指涉與任務還明確嗎？ |
| R | 純重述、空泛評價、播報 | 是否能指出它仍承擔上述任何功能？ |

R 只是候選。不要先按固定句型或詞表直接刪；「therefore」「observe」「we now」可能承載真正的推論或任務轉換。也不要把每個功能都變成單獨段落、Remark 或 Why。

### 5.2 最小刪除測試

1. 鎖定一個候選句與它的上下文；先列本單元所有數學／教學義務。
2. 指出它重述的**確切鄰近 span**，以及兩者各自承擔的功能。
3. 只刪這個候選，讓另一審查上下文回答固定問題：當前物件？假設？子目標？下一步合法理由？記號依賴？如何驗一個正例與反例？
4. 回答只能引用保留下來的正文。允許推論，但必須列出所用已讀先備；不得從模型知識庫補漏後說「仍很清楚」。
5. 若刪後任何必要答案無落點，恢復原句，或提出更短且功能相同的替代。
6. 最後核 PDF 及相鄰頁。來源精簡成功不等於單頁視覺負擔下降；LaTeX 可能把後文補入。

以上問答是缺陷探測，不是人類理解測試。AI 能回答不等於學生能答；AI 不能回答則可形成待核問題，不能直接宣布數學錯誤。

## 6. 可供研究試跑的 Prompt

以下是研究草案，不自動修改 A/B v4 角色責任。

### P-A：符號化前的等價與先備檢查

    你是研究審查者。輸入有：固定版本正文片段、前文已教的記號與定理、
    此單元數學義務、指定讀者範圍、候選改句。
    只使用這些材料判斷，不把自己的數學常識當作已教正文。
    先分列：
    (1) 所有物件及型別、定義域、陪域；
    (2) 所有假設、量詞、作用域與參數依賴；
    (3) 這是在定義/陳述/證明/舉例/解釋選法中的哪一步；
    (4) 新式子的每個記號在何處已教。
    對改句找一個最小反例或缺失假設，特別查空集、零值、非單射、
    多代表元、點態/一致、相等/同構。
    若認為等價，逐項對應數學義務；不要只說語意不變。
    另判斷是否刪去解碼、方法目的或防誤解功能。
    輸出 KEEP/EDIT_CANDIDATE/RETURN_CONTENT/UNKNOWN 及可定位理由；
    不輸出可讀性分數，不直接改正式正文。

### P-B：功能性重述與無用文字

    請讀完整推理單元及前後各一單元，逐句標 M/G/D/E/W/C/R。
    不要用句長、字數或口頭禪直接判定廢話。
    每個 R 候選都要列：它重述哪句/哪個式子；刪去後尚存的功能；
    原來可能避免的誤解；固定讀者任務是否仍可用正文證據回答。
    最多提出三項具體問題；沒有可靠缺陷可回 KEEP。
    對必要理由太少之處，列出缺的推理邊，不自行補成通過稿。
    對有價值但過長的句子，提供一個功能不變的最短自然替代。
    保留至少一個你主張不應刪的「看似重述」作負對照。

### P-C：避免作者自評熟悉效應

    你只收到固定先備、數學義務和匿名版本 X/Y。
    不提供作者理由、歷史分數、預期勝者或修改量。
    隨機化呈現次序；相同問題同樣問兩版。
    先完成解碼和理由定位，再看差異。
    對每個偏好指出可定位原因與反例，不以「較精簡」作理由。
    區分：數學缺陷、證據不足、讀者先備假設、版面疑點。
    允許兩版都好、兩版都不夠、無差異，並保留原稿作零修改選項。

此設計只是降低偏差的候選，沒有證明多模型必勝。獨立上下文與證據約束可能已夠；如果另一模型只重複作者偏好，不能算額外證據。數學內容異議仍按原角色責任處理。

## 7. 對本輪隔離實驗的建議

符號化與刪廢話應各自有單獨條件，再看結合條件。兩者的失敗機制不同：前者易改型別／作用域或增加解碼負擔，後者易刪去非命題性的教學功能。每個樣本都應有原稿不變的對照，且允許沒有改動。

建議固定少數可觀察任務而非加權可讀性分數：

- 能否從本文指出量詞中的依賴關係？
- 能否用新記號正確辨識一個正例與一個反例？
- 能否說出某個 proof step 所用條件與理由？
- 翻頁後能否定位當前物件、子目標、尚未完成的義務？
- 候選變短後是否更容易找到條件，或反而需要更多解碼與回找？

AI 可做上述定位與反例探測；真正偏好、理解、獨立應用和延後表現仍需真人任務。不能把模型可解碼或編譯成功標成達到 90 分。
