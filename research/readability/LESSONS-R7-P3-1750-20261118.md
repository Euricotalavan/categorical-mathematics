## 3. 有效做法：以數學閱讀單位決定斷點

1. **先固定真正編入 PDF 的來源。** 核三個 R7 ZIP 的位元、CRC／來源身份與 P2 修補位置。不要因目錄裡有多份歷史 TeX 就對第一個字串匹配檔直接改寫；要確定是被整合入口載入的活躍視圖。原 R7 保留，所有修補在獨立副本。
2. **先定位超標頁，再定位來源行。** 對每版 PDF 全頁計數；對高密度頁使用 SyncTeX 的 PDF→TeX 行號映射，查當下頁面究竟是哪個證明、例題、習題解答或目錄區塊構成。不能把舊物理頁碼當成重排後的恆定定位。
3. **以論證結構挑選分頁點。** 優先放在新命題、證明步驟、段落、習題／解答自然起點；不要任意切開量詞條件、相等鏈、對齊公式、交換圖或 LaTeX 不可跨頁環境。對不能安全縮短的長證明，寧可合理增加頁數。
4. **局部控制頁面容量，而非全卷改字級。** 曾嘗試明確換頁，後來以局部縮小當頁可排高度、必要時微幅放回可排高度的方式控制內容移動，例如有條件地使用 LaTeX 的 enlargethispage（負值／正值），並在精確位置修補而非改整份模板。
5. **極少量非語義文字精簡。** 刪重複說明、縮短轉場，但保留型別、量詞、假設、存在與唯一性、良定性、推理要點及完整習題解答；凡涉及數學語義或教學依賴都不是排版官可自行裁決的刪改。
6. **每次修補後重新編譯整卷並重測。** 讀取實際新 PDF 的逐頁數值，檢查最大值、中位數、短頁、頁腳間距、目錄、書籤、連結及診斷訊息。高密度頁的問題經常會從第 n 頁移到第 n+1 頁；只測修補過的原頁會漏掉連鎖副作用。

## 4. 最值得保留的失敗案例

### A. 句子變短，頁面未必變疏

先前 R6 → R7 → P2 多輪精簡，典型頁的有效字元中位數幾乎不變。TeX 會把後面的內容自動向前填入空出的區域，所以「少了幾句」不代表同一物理頁變得不擠。單靠改寫字句，不一定能達成明確的逐頁上限。

### B. 強制換頁降低密度，也會製造閱讀斷裂

早期把超標段落往新頁推時，V1、V2 曾出現章末只剩一兩行答案的短續頁，部分僅約 130 字元。這種版本即使統計變好，讀者仍須翻頁才能看完一個小結論。後續改為：識別是否真的是數學轉折，必要時讓前頁多容納一兩行，或撤回多餘的相鄰負縮頁指令；不能為了通過最大值就無限制地增加硬換頁。

### C. 修完本頁，又把下一頁塞爆

一段論證被移走後，新頁可能和既有例題／解答相撞；因此曾反覆出現「修掉舊超標，卻生出新超標」的情況。正確的迭代單位不是固定原頁碼，而是受影響的**連續閱讀區間**，最後以全卷 PDF 重新核驗。

### D. 只用截取字數會漏掉視覺問題

標準裁切可能漏到靠頁腳的內容，所以補做較低底界的裁切、正文／頁腳距離檢查與問題頁放大圖。零 overfull、零未解析引用或 PDF 可抽取，不等於沒有孤頁、公式跨頁斷裂或讀者難以追蹤的論證。

### E. 大量自動分頁有不同的風險

SyncTeX 可以大幅減少在數百頁教材中尋找 TeX 原文的成本，但其映射的附近仍可能包含數學環境、條列、標籤、宏命令和歷史備份。自動產生的候選必須限制為安全語法位置，再人工查分頁前後、重編確認；不應以候選數量或成功插入次數作成效指標。

## 5. 下一次更有效的工作準則（建議，未納入正式規範）

- 先產出逐頁異常清單（高字元、短孤頁、頁腳碰撞、公式超界、標題落單），按卷／章排序；給每項保存「所屬 PDF SHA、頁碼、同步 TeX 檔案與行號、擬議斷點、處理後相鄰頁」。
- 分兩種目標：**文字密度硬門檻**由工具全頁核；**真正的閱讀流暢度**需沿章讀到尾端，查概念、Why、推導、例題及續頁是否自然。兩者獨立驗收。
- 讓分頁優先遵循數學任務：給出輸入與條件、構造、驗證良定性／存在／唯一、反向證明、邊界案例、例題驗算。不製造無功能的大塊留白，也不為消滅留白把下一概念硬塞進來。
- 每輪只保存一個可追溯的現行來源及對應 PDF，原版獨立凍結；記錄總頁數、超標數、短頁數、修改影響範圍、來源/PDF hash。完成重建與安全性檢查，不要讓更新後的 TeX 繼續冒用舊版 manifest 驗收。
- 修訂進入內容語義時，按現行 A 工作流退精修／擴充／打厚，不准由排版的「減字」政策默默刪除量詞、先備或必要證明；排版後**只有打厚官**作全卷最嚴格數學終審與回修複核。
