## 1. 結論與證據界線

**最值得改進的是正文如何帶讀者完成一件數學工作，以及局部修改之後如何核對整章。** 全卷刪字、增加段落或套用同一視覺理念，都不能保證保留成功樣本的概念辨識、方法說明、例子銜接與章級整合。

本研究的起點是專案提供的一名讀者的歷史回饋：獨立的 V0 Chapter 1 S2.1 得到 93／100，後續 V0–V2 跨卷優化的整體回饋約為 60–65／100。這是不同文本與情境下的主觀閱讀感受，沒有控制內容熟悉度、難度、閱讀次序或裝置；**不是盲測、因果效果，也不是 R7 單一版本的正式驗收分數。** 研究不使用較早的50分作為這一整體回饋的現行值。

本輪已完成歷史來源與實頁比對、五種內容形態的二十份隔離原型、有限數學核對及研究 PDF 檢查。它支持一套可操作的診斷與修復方法，**尚不支持 AI 已能穩定產出90分以上教材，亦不能判定三種策略中哪一種對真人最好。** 沒有新增真人閱讀偏好、理解、獨立應用或延後保留數據。

建議的主體是：

1. 以讀者當前要判定、證明或使用什麼來組織正文。
2. 由與作者分開的診斷上下文先找可定位障礙，允許「沒有支持修改的缺陷」。
3. 依既有內容角色處理，不把所有問題交給排版補救。
4. 對照數學義務、相鄰正文與實際 PDF，驗證問題有解除且沒有新回歸。
5. 人類閱讀收益另行量測，不由工程通過、AI同意或數學局部核對代替。

## 3. 歷史比對的直接證據

### 3.1 章尚未結束，文字已經宣告轉入下一章

R7 V0 Chapter 1 的編譯入口依序載入 `01-opening`、`01-opening-solutions`、`b07-path-categories`，之後才是 Chapter 2。然而中間解答檔已先做章末回顧並預告下一章。

- 位置：`layout/views/v0/solutions/01-opening-solutions.tex` 第37–39行，PDF實體第45頁／印刷第33頁。
- 實際順序：下一頁，即PDF第46頁／印刷第34頁，仍在同章開始 paths；Chapter 2 要到PDF第53頁／印刷第41頁才開始。
- 編譯入口：`layout/study/volume-0-study.tex` 第19–23行。

這是可由來源和實際 PDF 核實的整合問題。局部句子可以通順，整章卻會先結束當前任務，再突然要求讀者重開新構造。檢查段長、字數或公式字串是否相同，不足以發現它。

研究提案是在保留數學範圍的前提下，將真正的章尾移到本章實際結束處，並接回反例所提出、尚未回答的構造問題。**本輪未把此修正套回正式或歷史書稿。** 缺陷的存在已核；它造成多少主觀分差仍未知。

### 3.2 定義之後，讀者何時第一次能判定一個模型？

S2.1 印刷第25頁在 category 定義後，立即檢查一物件一箭、兩物件加一箭兩個模型，然後指出箭頭不必是函數；下一頁才引入平行箭頭、endomorphism 與 identity 唯一性。R7 印刷第29頁則先接抽象術語與唯一性證明，第一個模型延到第30頁。

**已觀察的是順序差異；待驗證的是它對第一次學抽象公理的讀者有多大幫助。** 不能據此要求所有教材一律例子先行：S2.1 的 map 就使用精確定義先行，熟練讀者也可能偏好集中形式陳述。

兩份歷史文本還有內容差異，例如 S2.1 明列 Ob、Mor、source／target、Hom，而 R7 使用 dom／cod，沒有在此章採用同一段 Hom 記號。因此歷史比較不是只操弄敘事順序的受控實驗；本輪另外製作 E3，在固定義務下比較重排。

### 3.3 反例提出的問題與回應被隔開

S2.1 在一個缺少可用合成箭頭的失敗模型之後，直接引入 path 構造；同時保留有限列表所需的數學供給條件。R7 在類似反例與 paths 之間插入範圍說明、習題、解答與參考資料，三個印刷頁後才回到構造。

定位：S2.1 印刷第26–27頁；R7 PDF實體第43–46頁／印刷第31–34頁。

可提煉的原理是讓問題與回應相接，同時在使用前交代必要假設。這不構成刪除所有範圍說明或嚴謹性文字的理由。調動內容須由內容角色檢查先備與引用。

### 3.4 「套用相同理念」沒有保留同一份成功正文

S2.1 是獨立14頁稿，後續整卷 Chapter 1 具有不同載入順序、概念安排與章尾。R6到R7保留的是原有15頁整卷稿；不能把該章沒有繼續修改，說成保留了獲得93分的那份正文。

但不能把後續版本一概判壞：R7 成品有完整命題陳述、例子同頁等局部優點，其中有些在當輪之前已存在，不能冒稱是R7改稿成果。另外，實際R6到R7文字差異也有保留數學區別的合理精簡，例如V1 Ch27 §27.3.2將必要與充分條件所用假設並列。研究保留這些正面證據。

S2.1 本身也有例題、型別及解答末詞跨頁的問題。可成立的規則是保護必須一起使用的資料與理由，而不是要求所有數學單位都在同頁。

### 3.5 失敗紀錄對方法的約束

R6三卷合計841頁，沒有完成841頁連續人工順讀。較晚R7紀錄有92處保留分段、34處短句改寫，並記載因不良末頁而撤回的改動。這些數量描述工作量，不是品質效果。已撤回候選的相應 PDF 未取回，不能冒稱本輪看過那些失敗頁。

既有方法論本來就提過敘事、例子與QA。因此問題不宜簡化成少了一份更長提示詞；更需要檢查的是規則有沒有在實際正文落地、誰負責修改、何時核整合，以及證據不足時會不會停止擴張。

## 4. 三種策略與五組隔離原型

每組固定數學義務、共同先備與全局版式，保留對照0及三個策略條件：

| 策略 | 允許改動 | 適用問題 | 主要風險 |
|---|---|---|---|
| I：局部文字精簡 | 保持數學與次序，去掉確實無功能的重述 | 空泛導讀、迂迴句、重複收束 | 自然語言可能承載量詞、假設或辨識功能；公式不變不足以放行 |
| II：數學敘事重組 | 調整既有例子、說明與推導的次序 | 模型太晚、問題與回應分離、章尾失配 | 先用後教、符號指涉改變、小節標題或習題依賴失配 |
| III：整合式閱讀設計 | 在敘事基礎上處理文字功能及必要視覺提示 | 真正具有多個子目標的證明、複雜例題 | 同時改變多個因素；新增解說可能失準，標題可能引發分頁回歸 |

這些是套組比較，**不是完整因子實驗**。部分II延續I的精簡，III又增加方法說明與視覺提示；不能將0到III的差異單獨歸因於某一因素。另為E2建立了數學正文相同、步驟樣式不同的對照；研究樣本標識仍不同，這提供較窄的分頁觀察，不是對讀者效果的因果估計。

| 組別 | 材料及數學義務 | 已觀察結果 |
|---|---|---|
| E1：短定義 | 歷史map定義及兩例；域、陪域、唯一取值、相等慣例、重複輸出與未使用陪域 | 四版本正文完全相同；兩個診斷上下文都沒有硬選優勝。必要的辨識性重述保留，「不改」成為有效結果 |
| E2：抽象長證明 | R7 V1 Ch14 §14.2，PDF第40頁／印刷第32頁；指數物件構造、evaluation、兩層唯一性、比較同構與逆式 | 發現研究共同先備漏定義monic、product property過略，所有條件一起補齊；這不等於原書缺漏。同文的強步驟樣式佔兩頁，較弱樣式為一頁 |
| E3：連續抽象概念 | 歷史category資料、公理、術語、單位唯一性及五個模型／失敗候選 | II／III讓第一模型進入首頁；III新增說明曾把「同一合成算兩次」說成「比較同端點兩合成」，已單句修正。重排後小節標題涵蓋範圍仍未完全相稱 |
| E4：複雜線代例題 | 研究原創：在二次以下實多項式上，T(p)=p+p′；矩陣、特徵空間、不可對角化、可逆與原像 | 局部數學與精確代數核算通過；共同先備補三角矩陣特徵值定理。研究外加標題與長例框組合造成標題獨頁，未包裝成成功成品 |

E4 的逆算子為 `I−D+D²`，其中 `D` 是微分算子且 `D³=0`；`a+bx+cx²` 的唯一原像為 `(a−b+2c)+(b−2c)x+cx²`。本輪另以SymPy核對矩陣、左右逆、特徵資料及原像代回。這是有限代數檢查，不是整段教學的形式化證明或整卷終審。

研究 PDF 共40頁，團隊覆蓋了全部頁面的圖像檢查；部分以多頁聯覽，部分逐頁查看，不能稱為40頁同倍率連續精讀。E2較弱樣式的一頁安排只證明樣式改變了該例分頁，不證明一頁比較舒服。E4的孤頁發生於研究包外加標題，不外推為正式書稿同位置已有錯誤。

研究只做一次限定修復，保存修前證據，沒有為得到漂亮勝負繼續增輪。仍存在的E3標題問題、E4版面問題，以及尚未測得的人類成效，都保留為未決項。

## 5. AI如何自主找到閱讀阻力

診斷應找的是讀者為完成當前數學工作而被迫猜測、重建或搜尋的負擔，不是所有停頓與思考。證明理解不只包括每句的符號與理由，也包括整體方法、組織及轉用；這可作診斷問題的依據，但不是固定敘事順序的成效證明。[1]

眼動研究觀察到專家較常跨行回看，作者將其解釋為核對隱含理由；眼動本身不能完全揭示心理機制。因此不能以回看次數或速度單獨判品質。[2]

### 診斷輸入

- 截至此處讀者已學過的實際定義、定理及位置；不能只給籠統的「有基礎」標籤。
- 能完成一項工作的正文與必要相鄰段落，而非按固定字數任意截斷。
- 必須保留的數學義務及固定來源。
- 相應 PDF、實際頁序、穩定段落位置與編譯載入順序。
- 已知缺少材料，以及診斷範圍。

第一輪可隱去歷史分數、策略名稱、作者辯護與先前通過標籤，但不能因此宣稱完全盲化。不同上下文不等於不同模型；評審仍可能辨認風格、偏好長文或受到呈現次序影響。[8][9]

### 診斷步驟與缺陷格式

1. 先讀不改，指出當前要判定或建立的結果。
2. 每個關鍵步驟都指出正文先備；不得靠模型自行補足後宣稱原文足夠。
3. 對疑似冗餘，列出承擔同一功能的兩處位置，確認刪後不損害條件、辨識、方法或指涉。
4. 對疑似壓縮，寫出缺少哪個理由、哪個讀者工作無法完成。
5. 查實際章縫：問題何時回答、變量何時改變、章尾是否真在章尾、習題是否先用後教。
6. 記錄原文位置、影響、支持證據、可能推翻判斷的上下文、責任角色、最小修正與重核方式。

允許三種沒有立即改稿的結果：`NO_SUPPORTED_DEFECT`、`INSUFFICIENT_CONTEXT`、`HYPOTHESIS`。只有「不好讀」的形容，或模型總分上升，不足以支持批次改稿。

文字功能也不能只按是否新增命題判斷。例如「同一個N」提醒一致收斂的量詞；反例後恢復原序列，防止同名符號混用；說明常數不依賴極限參數，可能決定估計能否使用。這些都可能在公式不變時仍然不可刪。

外部自我修訂研究有成功與失敗結果，任務、外部回饋與呼叫成本不同，不能推出同一模型多問幾輪就可靠。[10][11] 長上下文研究也不提供本案通用的最佳長度；它支持保留逐項實讀與定位證據，而不是把整卷丟進上下文後假定都已處理。[12]

## 6. 放進現有角色，不新增逐章批准

以下是責任配置提案摘要，不替代現行規範，也不建立第二個終審權。

| 角色 | 應處理的閱讀問題 | 邊界 |
|---|---|---|
| 擴充 | 整卷與本節敘事、例子與方法承接、先備次序、章尾和後章接口 | 涉及範圍爭議依既有規則；不可擅改卷界或章號 |
| 打厚 | 必要型別、量詞、相等、良定與推導展開；辨識例是否足夠 | 保持唯一嚴格整卷終審與修後複核；不先腦補缺口再判原文通過 |
| 精修 | 來源逐項核對、安全精簡、必要理由保護、調動後的依賴與章卷整合 | 大幅結構問題交擴充，展開不足交打厚；語意疑問不讓排版自行決定 |
| 排版 | 圖文與公式條件的實頁安排、Remark與工作階段的視覺辨識、全頁核查 | 不用工程通過代替數學或閱讀驗證；先備或含義改動交內容角色 |
| 版本協調 | 固定來源、傳遞交接、保存缺陷與修正紀錄 | 不以行政搬運代替專業審核 |

A保留既有整卷製作順序；B保留依依賴逐節製作及章卷整合順序。閱讀診斷嵌入已有工作，而不是要求每節都多跑一套評審投票。逐節修補與角色間退回自主進行，**不增加逐章等待使用者批准**。

## 7. 擴展至162卷的採用條件

不建議以全卷統一字數、段數或例子數作主體。較值得有限驗證的是：**代表正反例校準＋全正文診斷＋按責任修正＋章卷整合**。

案例庫應保存成功的功能與失敗邊界：讀者先備、原文與修後文、數學義務、真實PDF落點、修改原因、未改善之處、是否存在真人資料、版本與失效條件。校準例與未知驗證例分開；同一證明換符號不是充分泛化證據。

| 領域 | 應優先追蹤的內容 |
|---|---|
| 範疇論 | 箭頭型別、泛性量詞、唯一性、是否能使用元素直觀 |
| 線性代數 | 向量與座標、基底與矩陣、運算與結構結論的對應 |
| 分析 | 量詞依賴、點態與一致、局部與全局、估計及極限交換條件 |
| 拓撲 | 一般定義與度量直觀的差別、子空間／積／商及序列判準的邊界 |
| 幾何 | 座標與內在物件、局部到全局、轉換及粘合相容性 |
| PDE | 函數空間、邊界項、常數依賴、弱／強收斂與極限傳遞 |
| 抽象代數 | 商與代表元、良定性、假設如何支持構造 |
| 高階研究生數學 | 真正新困難、先修定理的精確版本、長程引理用途 |

這是跨領域設計提案，尚未完成上述全部領域實驗。規模化依次增加未知因素：新的同類片段、完整章、整卷與跨卷接口，最後是不同領域。每次都要保數學、查回歸，模型或模板變更後重新核受影響項。

若要對真人宣稱穩定90分，必須先固定評分對象、裝置、難度與閱讀長度；再用未參與調稿的新樣本，分別測閱讀偏好、理解、無提示應用及延後表現。歷史讀者偏好是重要校準，但其他讀者資料不保證同一個人的感受，反之亦然。

同題多版給同一人連續看會受重讀污染，可將同題不同版本分配給不同讀者，在難度相近的主題間輪替策略與次序。測驗由數學目標事先制定，數值容忍度與決策規則在正式試驗前固定。本輪沒有可支持樣本量保證或效率百分比的數據。

## 8. 停止條件：防止再次大改數百頁而缺少收益

| 訊號 | 必要處理 |
|---|---|
| 只有字數、段數、頁數、編譯警告或AI評分變好 | 停止擴大該改法，回查它究竟要消除哪個缺陷 |
| 刪掉量詞、假設、必要理由，或產生先用後教 | 撤回受影響修改，重核數學義務與傳遞影響 |
| 解一處卻造成同等或更嚴重中斷 | 保留原稿或最小已證改善；把新缺陷列出，不能以總修改量抵銷 |
| 對調版本次序後偏好隨位置改變 | 將偏好結論列不穩，回到定位證據；不以投票強行決定 |
| 同一處反覆加字／刪字而問題未解除 | 停止原假說的推廣，轉查上游結構或內容界線 |
| 來源、上下文或PDF身分不一致 | 補足受影響材料；不把不完整研究包誤認為正文缺漏 |
| 沒有真人資料，卻要聲稱90分或策略優勝 | 保持未驗證狀態；不製造分數或保證 |

停止的是無證據策略的擴張，不是容忍必要缺陷。既有凍結與授權界線維持；研究提案公開也不自動授權重啟書稿。
