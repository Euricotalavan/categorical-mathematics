# 重用 v8 成功經驗：角色操作草案

2026-11-19 · v1。依據 [成功分析](SUCCESS-ANALYSIS.md) 的實際案例；不是正式模板或 A／B 工作流升版。使用者已滿意的 v8 保留。本草案僅供後續**已授權**工作使用，不新增逐章等待批准。

## 先記住三件事

1. **先證明內容還在，再談變短。** 型別、量詞順序、條件、存在／唯一／良定、推理及必要例子不得因精簡消失。
2. **讀者已會的才可縮寫。** 可以重用已讀定義；第一次教的新概念仍須能辨認、解碼和使用。
3. **改完看整個閱讀單元。** 看來源 diff 不夠；公式、條件、理由、題目資料與解答在 PDF 裡是否容易接續，須另外確認。

## 每個候選修改，使用這張小問題單

只為具體疑點填寫，不要求每個正常句子產生紀錄。

| 欄位 | 必須回答 |
| --- | --- |
| 定位 | 固定版本、來源路徑／行、PDF 實體頁、完整相關單元 |
| 讀者的任務 | 現在要判定什麼、推導什麼、使用哪個已讀定義？ |

## 六個可直接使用的審查問題

### 1. 可以引用已學結構嗎？

參考 Def 10.1：同一個積的完整普遍性不必在後續每章重講，但要核這次的物件、型別、適用條件和外層存在量詞。保留「見證先固定，再選測試資料」這類容易誤讀的依賴。

若需要讀者跳過尚未教的先備才能懂縮寫，判 KEEP 或退精修／擴充。不能把「引用一個名詞」當作定義真的已可用。

### 2. 重複資訊能否放到共同位置？

參考逆映射表格：五行相同的 `B→A` 可上提成表頭 `Hom𝒞(B,A)`。逐步理由仍留在每行。如果某行型別不同，就不能整欄合併。

在分析中，共同的常數依賴或量詞範圍也可能集中說明，但若作用域改變、條件跨頁難找，便不算改善。

### 3. 這句文字有什麼工作？

保留：目標、選法、先備解碼、推理合法性、量詞依賴、反例辨識、易錯警語，以及必要的前後銜接。

可刪候選：已由緊鄰公式完整承載且沒有額外教學作用的播報、重複強調、空泛轉場、機械總結。

遮掉候選句後，只靠已讀正文問四件事：現在證什麼？這一步為何合法？哪些條件在用？下一步可用什麼？答不出且需要模型自行補理由，就不是已證冗餘。此測試是診斷，不是人類理解測驗。

### 4. 符號是否真的減少解碼工作？

只有已學記號、清楚型別和作用域才可安全使用。避免為省一行另造新記號。不得把 `f(A)⊆B` 偷換成原映射的陪域已變成 B，不得把 `≅` 換成 `=`，不得改量詞順序，也不能用 `∃!` 代替存在與唯一證明。

### 5. 翻頁時，讀者還知道正在做什麼嗎？

短定義、短題目及其資料優先保完整；長證明可在子目標完成後續頁。不要把多頁證明整體鎖進不可分割容器。條件、式子、圖與解說的距離須按實際任務判斷。

改動後讀完整單元與前後頁；若重流繼續影響後文，沿影響擴查。正式初次排版審查仍依 v4 全頁視檢與章級順讀，不能拿這份研究的抽樣取代。

### 6. 這頁較密，是問題還是內容需要？

字元計數只報位置，不給可讀性分數。習題題目可緊湊；混合頁分區看；習題詳解看推理。章末短頁不自動失敗，高密頁也不自動刪文。

另查真正的幾何問題：正文／頁尾碰撞、裁切、公式溢出、孤立續句。v8 兩個頁尾重疊的反例說明，即使內容完整抽取，畫面仍可能有錯。

## 依現有角色使用，不改流程

| 角色 | 研究草案要求 | 原階段映射 |
| --- | --- | --- |
| 擴充 | 安排先備、例子、目標與相鄰關係；避免每段機械加動機 | A04；明確已選 B 時 B-02／B-04 |
| 打厚 | 完整展開義務與必要理由，指出哪些說明不能刪；展開階段不提前以短度為目標 | A05；已選 B 的 B-04 |
| 精修 | 實讀先備／來源後核安全縮寫、共同條件上提與刪冗；查直接及傳遞依賴 | A06–07；已選 B 的 B-04／B-05 |
| 行文排版 | 只處理可確定不改語義的行文及版面；看重流、章縫、頁尾、題目／詳解 | A08–09；已選 B 的 B-06 |
| 打厚終審 | 對固定最終正文與 PDF 獨立整卷核查；所有回修再複核 | A10–12；已選 B 的 B-07 |

量詞、型別、定義、證明、先備或相等關係有疑問，退相應內容角色。排版不替代數學裁決。局部研究核查、AI 交叉同意和 hash 通過都不能替代唯一打厚整卷終審。

## 後續如何檢驗「不用逐章教 AI」

在已授權後續工作中，記錄問題由誰先發現、是否需使用者給逐處改法、改後是否仍有同類錯誤，以及整合後是否回歸。少量代表單元校準應產生可重用的正例／反例，不能變成永久逐章人工教學。

只有案例可重現、數學義務保留、PDF 沒新增缺陷時才擴大。若章級或全卷整合失敗，回到責任角色處理原因，不以增加代理、增加輪次或降低字元上限掩蓋。

本案已證明此次 v8 得到滿意回饋；未證明零逐章指導的自主產出或跨 162 卷穩定 90 分。保存成功方法與這個未知，兩者都必要。

## 重核研究資料

在本目錄執行：

```sh
python tools/verify-success.py
python tools/recompute-success-metrics.py --output-dir /tmp/cm-v8-metrics
```

前者只驗研究檔案完整性；後者從固定公開來源重算描述統計，寫到隔離目錄。兩者都不產生閱讀分數、不替代數學終審。

持有原始 P2／v8 reading PDF 時，可執行 `tools/verify-success-pdfs.py --p2-dir <P2目錄> --v8-dir <v8目錄>` 重核身份與逐頁字元。每個目錄需保留三個 `volume-N.pdf` 原檔；私有歷史檔不由此工具搜尋或公開。

`tools/build-success-html.py` 可由 Markdown 重建報告 HTML，使用固定公開 v8 PDF 生成圖；需要 Python 的 Markdown 與 PyMuPDF。它不編譯或修改教材，HTML 內的圖來自已公開 v8，沒有重新公開歷史 P2／P3 整頁。
