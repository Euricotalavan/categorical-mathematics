# 高可讀性數學教材的穩定製作方法論 v1

**文件類型：**研究結論的統一整理／**提案，未生效**  
**整理日期：**2026-11-17  
**範圍：**數學教材的閱讀體驗、行文排版、LaTeX 可重用架構與工程驗證  
**排除：**不修訂已發布書稿、不修改正式 Study、不變更 A/v3 或 B、不宣稱全卷數學驗收或任一教材已「穩定 93 分」。

## 0. 最重要的總結

> **讓數學主導閱讀；讓讀者能快速看見重點、就地理解必要理由，自然連續地往下讀。**
>
> **讓排版規則可重用，讓每一次修改都能查出它改壞了什麼。**

這不是「把書縮短」「加入更多直觀敘述」「每頁加彩框」，也不是直接套 ElegantBook。使用者喜歡的是：高可辨識的數學層次、乾淨的正式論述、寬鬆的行間空間、就地可見的補充、讀下去不必時常猜符號或回找上下文。此偏好還需在不同內容與裝置上驗證。

**品質優先順序**：數學正確與來源責任不可犧牲 → 讀者能依已讀正文正確使用 → 閱讀連續性與實際理解 → 版面美觀 → 在前述品質成立時再比較 Token／人工成本。

## 1. 認知與寫作：消除「沒有教學作用的摩擦」

### 1.1 兩種困難必須區分

- **值得保留的數學困難**：理解新概念、檢查假設、建立證明、解決新問題。
- **應減少的閱讀摩擦**：符號首次使用不明、長句遮蔽條件、與公式重複的自然語言、圖與公式相距太遠、為查 Why 被迫跳頁、無意義分頁和標記過多。

不以「讀起來無痛」替代真正學習。流暢度、好奇心、認知負荷及心流可以提供**設計假說**，不是已對本套書驗證的神經科學因果機制，也不能以「多巴胺」一句話解釋。

### 1.2 敘事與行文各自負責什麼

- **正式數學是正文主角**：完整寫出對象、型別、量詞、前提、相等／運算、命題與必要推理。數學必要性不因視覺上次要而改成選讀。
- **自然語言以短句完成任務**：指出此步目的、關鍵選擇、假設用途、反例揭露的障礙或下一步的連接。不把已清楚的等式換句話再說一遍。
- **有進展的閱讀順序**：當依賴允許，讓關鍵定義靠近可操作的例子，再從例子／公理進入命題與證明。這是候選教學設計，任何移動影響先備、型別或結論均須由內容角色核實；排版官只做定位、提議及非語義修補。
- **一段文字應有獨立作用**：同一結論不要在引言、Remark、Why 連續講三遍；若三段內容作用不同，應能清楚指出差別。

### 1.3 「重點先行，理由就地」

短 Remark 可有兩個視覺層次：

1. **Key statement**：一句醒目的核心觀察，例如「A morphism need not, by definition, be a function.」
2. **Why?**：在同一框內、緊接下方，以較安靜但清楚可讀的字體提供簡短依據。無須跳轉到後頁。

這不是將必要證明藏起來的方法：若 Why 含非平凡的定義證明、良定性或必要引理，它應回到正式正文或證明環境。也不是每頁強制放 Remark；這個設計只有在有清楚概念價值時才使用。

## 2. S2.1 校準風格：固定功能，不僵化所有數值

S2.1 是 V0 **Chapter 1（不是 Chapter 0）** 的隔離閱讀試驗，受一位讀者主觀評為 **93/100**。它經歷了行文、敘事、布局和字級多次修改；不能將得分歸因於單一參數。

| 特徵 | 可重用的設計判準 | 已知校準起點／邊界 |
|---|---|---|
| 字級與行距 | 字的視覺重量適中，但每行有呼吸空間 | 正文 **10.4/16.0 pt**；上游 S2 為 10.8/16.2 pt。較小字不是普遍最優。 |
| 標題層次 | 容易掃到章節和數學單元，但不與公式爭注意 | 章題約 22 pt、節題約 13.5 pt；可依裝置校準。 |
| 紙面與行寬 | 暖白、高對比、行不過長；數學與段落有清楚分界 | S2.1 研究記錄約 **190×260 mm**、左右邊界 **27 mm**；不作全領域硬限制。 |
| 定義 | 淡青綠結構，讓型別和公理先被看到 | 完整定義與條件不能因框太長而被截斷。 |
| Remark | 鮮明金色框＋醒目結論＋就地 Why | S2.1 key 約 11.8/17.6 pt、Why 約 9.4/13.9 pt；短框儘量同頁。 |
| 命題與證明 | 比 Remark 安靜，公式與推論為主 | 長證明允許合理分頁及續接提示。 |
| 數學記號 | 清楚而不花俏；同一作用域不默默換型別 | `\mathsf C` 是此**試驗版**選擇，不代表已改全套書範疇記號政策。 |
| 色彩 | 區分內容功能，而不是裝飾 | 不只靠顏色：名稱、字重、線條仍應可在灰階辨認。小金字需足夠對比。 |

S2.1 的相對行距從 `16.2/10.8=1.50` 到 `16.0/10.4≈1.54`。這是可核算的幾何變化，**不是「縮字造成 93 分」的因果證據**。字型、實際顯示尺寸、視力、內容熟悉度和裝置縮放也會影響體驗。

## 3. 用「閱讀單位」決定排版與分頁

**閱讀單位**是理解當下這一步所需一起看到的材料；不是將每一節都做成盒子。

| 內容類型 | 優先安排 | 避免的失敗 |
|---|---|---|
| 短定義／短命題 | 標題、關鍵條件及結論盡量同頁；不得省略型別、量詞 | 標題孤立在頁末；為省空間刪必要條件 |
| 長定義／長敘述 | 可拆分，續頁維持原編號及識別 | 整段不可拆造成頁外裁切；續頁像新定義 |
| 短 Remark＋Why | 重點句與其短理由就地同頁 | 核心在本頁、Why 被迫跳到下一頁；又在別處重述重點 |
| 長證明 | 按有意義步驟續頁，保留所證命題；數學推導自然分段 | 將整篇證明鎖進不可分盒子／`minipage` |
| 十幾行以上公式 | 選適合斷行與分頁的公式環境，核等式連續與項目完整 | 在不可跨頁的 `aligned`／`split` 裡堆長式；整體縮到難辨識 |
| 寬矩陣／交換圖 | 優先調整表示、分塊、公式布局或明示寬頁，內容角色核語義 | 自動替換數學記號、默刪方塊、圖越界 |
| 圖與例子 | 圖與相關定義／驗證條件相鄰；必要時精確回指 | 圖漂到遠處，讀者反覆翻頁 |
| 演算法／長表 | 標明程序身份、完整初始化與停止條件；續頁重複表頭 | 表格列/演算法分支失蹤、末頁只剩幾行 |
| 習題與解答 | 可導航、問題與解答能定位；正文與解答的教學責任分清 | 因為「爽讀」就消除讀者必需自己解決的挑戰 |

**不要以頁數、文字量或框數設定完成門檻。**較多頁可以接受；過長的孤立末頁仍應檢討。必要時使用局部 `needspace` 或保護短單位的環境，但應紀錄原因並重核前後頁；不是以全局 `\newpage` 解決一切。

## 4. 可維護的實作：唯一正文＋薄樣式層＋多輸出設定

推薦研究架構 **Ⅱ**：

```text
content/              # 唯一正式數學正文，包含已核標籤與條件
  chapter.tex
  notation.tex         # 明確記號政策；勿由樣式猜語義
style/
  readflow.tex         # Definition、Remark、續頁及視覺參數
profiles/
  screen.tex           # 暖白閱讀版
  print.tex            # 白底或灰階版
  large.tex            # 較大字的壓測版，非自動無障礙合格
checks/
  qa.py                # 編譯/字型/頁界/引用/預期內容/渲染核查
```

以上為**提案中的概念分層**；不是已採納的檔案結構。內容作者標記「這是短 Remark」「這是長證明」「這是必要假設」，模板處理版式，不能讓模板判定何者數學上可省。只在需要一致管理的內容上引入少量自製命令；普通敘述與公式繼續使用標準 LaTeX。

三種可行架構的取捨：

- **Ⅰ 複製 S2.1 並逐頁手調**：初期容易，但每卷可能分裂出不同 preamble、硬換頁與無法追溯的例外。
- **Ⅱ 薄語意排版層（推薦試行）**：一套樣式、少量語意標記、維護局部例外，搭配自動測試與完整視檢；成本和風險較可控。
- **Ⅲ 完整結構化出版系統**：可能利於多輸出和長期管理，但遷移、數學語義保真與維護負擔很高；本次未做實測，不應先行全面投入。

**沒有實測全套書的 Token 優勢**。節省方向是避免重造樣式、重輸出已核正文與重填機械交接；不可省掉定義、來源覆蓋、證明或整卷閱讀。

## 5. 行文排版官的權限與 A／B 接入

排版官沿正文順讀，以四類記錄問題；先定位，再修補：

| 類型 | 例子 | 誰能修 |
|---|---|---|
| L：Layout | 行距、公式越界、圖文分離、色彩、分頁 | 排版官可直接修，但保留數學與核修改範圍 |
| E：Editorial | 重複說明、非必要冗句、段落銜接 | 排版官可作非語義局部 patch；有數學疑問即退精修 |
| N：Narrative／prerequisite | 例題過晚、先定後用、章節結構跳躍 | 擴充安排，精修核先備／數學；排版官只提出定位和修法候選 |
| M：Mathematical | 型別、量詞、相等、良定性、漏假設、跳證 | 精修／必要時打厚；排版官不得自行補證後放行 |

- **A/v3**：於第 08–09 步接已完成打厚與精修的固定內容；完成候選後只交打厚第 10–12 步整卷終審。
- **已明確選 B 的卷**：於 B-06 接 B-05 **章級及整卷整合完成**的固定正文；完成後只交打厚 B-07 終審。
- 未選 B 的卷繼續依 A/v3。**不能復活排版後擴充／精修各一次意見或兩份 `NO OBJECTIONS` 結案。**
- 發現數學或敘事缺陷只退受影響範圍；任何修復後回打厚複核。dot 只管版本／搬運／協調，不逐段審數學。
- 每次交接列 A/B 採用依據、輸入版本、實讀範圍、來源與 PDF 配對、差異、OPEN/UNKNOWN、下一步和實際送達／讀入狀態。

## 6. QA：三層核查，三種不同「通過」

| 層次 | 必查 | 自動化限度 |
|---|---|---|
| **數學與內容保留** | 固定來源／覆蓋表、語義 diff、型別與條件、原文落點、標籤、影響傳遞 | hash 可發現變更但不會判斷數學真假；數學疑問退內容官 |
| **工程檢查** | XeLaTeX/latexmk、字型、超界、預期標識、未解析引用、連結／書籤、PDF／來源配對、乾淨重建 | exit 0、文字可擷取與渲染正常不保證沒有隱藏／裁切內容 |
| **閱讀檢查** | 全頁依序視檢、異常頁放大、Remark/Why就地、圖與公式接近、跨頁連續、全文順讀 | 頁面密度和警告數只能當優先處理線索；不能代替人工判讀 |

改字型／行寬／環境時，重跑所有受影響輸出和頁面。數學假設、定義、符號與依賴變動時，舊語義驗收會對相關下游失效；影響不明則擴大核查。**PDF 字元或頁數相同，不等於語義／視覺未變；逐像素相同也只證明特定渲染設定下的外觀相同。**

要同時測「正向」與「故意失敗」的試片：不可拆的長公式、超寬矩陣、壞引用、意外白字、過密／稀疏頁、跨頁 Why、長證明及表格。測試成功應代表抓到已知問題，不是把故障 PDF 認證為合格。

實務操作的逐階段清單見 [EDITOR-QA-v1.md](./EDITOR-QA-v1.md)。

## 7. 讀者試驗與採用門檻

**不要拿歷史版本的 30→50→82→93 當同內容、盲測或因果證據。**要驗「模板」的效果，至少做：

1. 同一固定數學正文，只改版面；在相同裝置／縮放與閱讀條件下比較。
2. 同一版面，由內容角色**授權**調整敘事順序，再查數學責任及所有先備。
3. 同一模板，放入不同領域、不同篇幅的未讀材料；含長證明、複雜公式、圖、習題。
4. 將**願意持續讀／閱讀摩擦**、**能否獨立判定／應用定義**、**近遷移解題**、**延後記憶**分開測；不能只看「我覺得懂」。
5. 對照工程費用：模型 calls、實際 tokens、人工分鐘、返工次數及新引入錯誤；未知就標 `UNKNOWN`。

採納前必要條件：已知阻塞工程缺陷與語義缺陷解決；代表場景全部渲染與順讀；所有來源責任、數學與重要未解如實揭露；實機偏好和理解不呈現重大退步。正式整卷仍由打厚官依已授權流程最嚴格終審。

### 8.3 代表性的失敗教訓

- `\begin{aligned}` 類不可拆容器塞入過長推導：可編出 PDF，卻出現嚴重垂直溢出；修復版用可分頁的數學環境保留全部項目。
- 長公式整行超過頁寬：分行、重核條件和運算順序，不靠整段縮字。
- 可拆 Remark 的關鍵句與 Why 被分到兩頁：短單元採合適的不可拆／預留空間機制，**長**論證則不可使用同樣限制。
- 意外白色文字出現在淺色正文：PDF 仍可能可抽取文字，須另查顏色／對比與像素實際可見性。
- 小字金色在淡金底對比偏低：保留金色邊框，調深小字。兩份原型曾用不同的金字參數，**不可假稱它們是同一版的測試值**。
- 為修復圖文分離增加局部留白，可能導致後續標題孤立；需核相鄰頁及連鎖變化。

### 8.4 未解／禁止的宣稱

- `OPEN-READ`: 尚未證明新模板在真人、真實裝置、未讀材料的連續閱讀與解題上維持 90+ 的偏好。
- `OPEN-CONTENT`: 新研究原型不是正式數學教材；未經獨立打厚整卷審核，不得當作卷別已通過。
