# 數學教材可讀性與排版製作方法（研究草案）

> **狀態：研究彙整 v1（2026-11-17）；不是已採納的模板或工作流規範。** 這個資料夾僅放原創方法論文字，不含第三方教材、字型、未公開正式稿、PDF 或任何機密。已發布的 `archive/v0`–`archive/v2` 不受影響。

本方法來自 V0 Chapter 1 的 S2.1 閱讀試驗及兩次獨立的可讀性／出版工程研究，目標是將「讀者願意連續往下讀」轉化為**可操作、可追溯、可測試**的教材製作流程。

**核心原則：**數學主導閱讀；形式條件不省略；醒目的重點與簡短的理由靠近呈現；跨內容共用一份數學正文與一層薄排版規則；每次修改重新核查受影響內容和頁面。

- [完整方法論與研究證據](./METHODOLOGY-v1.md)：設計思想、版面參數起點、內容類型、A/B 接入、兩組工程測試與尚未解決的風險。
- [行文排版官操作與 QA 清單](./EDITOR-QA-v1.md)：接收、分類、編譯、視檢、交接、退回的可直接執行步驟。

## 適用邊界

- **工作流 A**：以《四官製作與交接總規範-v3.txt》為準；本研究只提出第 08–09 步的可用方法。
- **工作流 B**：必須有本卷明確選用 B 的授權，才適用 B-06；本研究不讓 B 自動生效。
- 排版不替代數學嚴謹、逐項文獻覆蓋或定義可用性審核；排版完成後，**只交打厚官做最嚴格的固定整卷終審**。
- 本資料夾是**研究文字**，不是「正式 Study 模板」或完成教材的承諾；研究原型也有尚未解決的編輯警示。

## 成功的判準不是「再出現一次 93 分」

S2.1 得到一位讀者的主觀評分 **93/100**；此前的 30／50／82 分與另一教材的 90 分都只是不同內容、不同版本的個人閱讀回饋，**不是對照實驗或可歸因的提升幅度**。未完成跨領域真人閱讀、理解、延後測試前，不聲稱可穩定得到相同分數。

研究輸入的固定版本、工程驗證範圍和兩項研究成果的差別，請見 [方法論的「證據與版本」章](./METHODOLOGY-v1.md#8-證據版本與已知限制)。
